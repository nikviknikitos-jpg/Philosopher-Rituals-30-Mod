# Philosopher's Stone (Философский Камень)

Алхимический мод для **Minecraft 1.20.1** на **Forge** (MDK 47.x).

## Возможности

- **Философский камень** (`philosophersstone:philosophers_stone`) — предмет с 30 зарядами:
  - ПКМ по блоку — трансмутация:
    - Камень → Золотая руда
    - Булыжник → Блок необработанного золота
    - Глубинный сланец → Золотая руда глубокого сланца
    - Адский камень → Светокамень
    - Земля → Глина
    - Песок → Стекло
    - Железная руда → Золотая руда
    - Диорит → Кварцевый блок
  - ПКМ по воздуху — чинит первый повреждённый инструмент в инвентаре (+5 прочности за использование).
- **Эссенция трансмутации** — крафтовый материал; 4 штуки в руке превращаются в золотой самородок.
- **Алтарь трансмутации** — декоративный неубиваемый вручную блок (светится).

## Крафты

| Результат | Рецепт |
|---|---|
| Эссенция трансмутации (x4) | Золотые блоки крестом + blaze powder в центре |
| Философский камень | 8 эссенций вокруг dragon breath |
| Алтарь трансмутации | Обсидиан + алмаз + незеритовые фрагменты |

## Сборка

```bash
./gradlew build
```

Готовый jar появится в `build/libs/`. Для запуска в dev-среде:

```bash
./gradlew runClient
```

Требуется JDK 17 и интернет для первой загрузки Forge MDK.

## Структура

```
src/main/java/com/example/philosophersstone/
  PhilosophersStoneMod.java      — класс мода
  item/ModItems.java             — регистрация предметов
  item/PhilosopherStoneItem.java — логика камня (ремонт, тултип)
  block/ModBlocks.java           — регистрация блоков
  event/ModEventSubscriber.java  — трансмутация блоков по ПКМ
src/main/resources/
  META-INF/mods.toml             — метаданные мода
  assets/philosophersstone/      — модели, текстуры, локализация (ru/en)
  data/philosophersstone/        — рецепты, таблицы добычи
```
